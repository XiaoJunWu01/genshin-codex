# 观测枢图鉴

适用于 Miao-Yunzai / Yunzai-Bot V3 的原神图鉴插件。数据来自米游社观测枢公开词条，查询后渲染成图片。

## 安装

```bash
git clone https://gitee.com/wubaojun/ys-wiki-plugin.git ./plugins/ys-wiki-plugin
```

然后重启 Yunzai。

## 指令

| 命令 | 说明 |
| --- | --- |
| `#图鉴帮助` | 查看帮助 |
| `#角色 胡桃` | 角色图鉴，含各阶段突破材料和天赋升级材料 |
| `#武器 狼的末路` | 武器图鉴，含各突破阶段材料和满级合计 |
| `#圣遗物 绝缘之旗印` | 圣遗物套装与单件 |
| `#敌人 丘丘人` | 敌人图鉴。`#怪物`、`#魔物` 相同 |
| `#食物 甜甜花酿鸡` | 食物图鉴，含加工材料和不同品质效果 |
| `#材料 霓裳花` | 材料图鉴。`#素材`、`#道具` 相同 |
| `#图鉴 银釭` | 不限分类搜索，唯一结果直接出图 |
| `#图鉴 武器 狼末` | 可加分类，也支持简称 |
| `#图鉴2` | 打开上一次搜索的第 2 条，10 分钟内有效 |
| `#图鉴目录 武器 2` | 浏览分类，可翻页 |

角色卡会展示突破材料、满级合计和 LV2 到 LV10 的天赋升级材料。武器卡会展示每个突破阶段的材料。食物卡会展示食谱材料。敌人卡会展示掉落和参考数据。

## 说明

- 裸写的 `#胡桃` 不会触发。必须写分类，例如 `#角色 胡桃`，或使用 `#图鉴 胡桃`。这样可以避免和其他插件的 `#角色名` 指令冲突。
- 观测枢没有单独的“魔物”分类，`#魔物` 查询的是观测枢“敌人”分类。
- 同名内容可能同时有游戏本体和七圣召唤卡牌。插件会优先本体；仍有多个结果时先给列表。
- 卡片图片、名称、数量和图标都来自观测枢接口。接口没有提供的数值不会自行补算。
- 底图默认读取 `resources/background/bg.png`。可复制 `config/config_default.json` 为 `config/config.json` 修改底图、透明度和模糊。

## 目录

```text
ys-wiki-plugin/
├─ apps/wiki.js      指令与图片渲染
├─ model/wiki.js     观测枢搜索和词条解析
├─ config/           底图与样式配置
└─ resources/        默认底图
```
