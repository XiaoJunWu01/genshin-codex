# 观测枢图鉴

Yunzai-Bot V3 插件。查询原神、崩坏：星穹铁道、绝区零的公开图鉴，并把结果渲染成图片。

原神数据来自米游社观测枢，星穹铁道和绝区零来自对应游戏的公开图鉴。新内容随图鉴更新：目录缓存 6 小时，搜索和词条缓存 30 分钟，到期后自动读取最新词条，不需要为新角色修改插件。

## 安装

本插件运行在 Yunzai-Bot V3 里，需要先装好机器人本体。Miao-Yunzai、TRSS-Yunzai 以及其他 Yunzai V3 分支都可以。Yunzai 自带插件框架、Puppeteer 截图和 node-fetch，本插件没有额外的 npm 依赖。

在 Yunzai 根目录执行：

```bash
git clone https://gitee.com/wubaojun/genshin-codex.git ./plugins/genshin-codex
```

安装后重启 Yunzai。发送 `#图鉴帮助` 查看原神说明，发送 `s` 或 `z` 查看星穹铁道和绝区零的指令。

### 必须

| 插件 | 作用 |
| --- | --- |
| Yunzai-Bot V3 | 机器人本体。提供消息插件、Puppeteer 截图和网络请求。没有它，本插件无法加载，也不能出图 |

不需要单独安装 puppeteer、node-fetch 或其他图鉴插件。

### 可选

俗称不是图鉴接口提供的。不装下面的插件，正式名字仍然可以查询，例如 `g胡桃`、`s流萤`、`z爱丽丝`；`g雷神`、`g绿剑` 这类俗称需要对应插件的别名文件。缺哪个就跳过哪一份，不影响其余功能。

| 插件 | 作用 |
| --- | --- |
| [miao-plugin](https://github.com/yoimiya-kokomi/miao-plugin) | 原神角色、武器、圣遗物俗称；星穹铁道角色、光锥、遗器俗称 |
| [StarRail-plugin](https://gitee.com/hewang1an/StarRail-plugin) | 星穹铁道角色俗称 |
| [ZZZ-Plugin](https://gitee.com/ZZZ-Plugin/ZZZ-Plugin) | 绝区零角色俗称 |

原神角色俗称也可以读取 Yunzai 自带的 `genshin` 插件别名。

## 指令写法

原神指令支持三种写法，效果相同：

| 写法 | 示例 |
| --- | --- |
| `#` 开头 | `#图鉴帮助`、`#角色 胡桃`、`#图鉴今天` |
| `g` 开头 | `g图鉴帮助`、`g角色 胡桃`、`g图鉴今天` |
| `#g` 开头 | `#g图鉴帮助`、`#g角色 胡桃` |

星穹铁道用 `s`，绝区零用 `z`。`s流萤`、`#s流萤`、`s 流萤` 是同一条指令。`#星铁`、`#绝区零` 也能用，不会占用原神的 `#角色`、`g名字`。

空格可有可无。`#g天赋 胡桃` 和 `g天赋胡桃` 是同一条指令。下文原神指令只列出 `#` 写法。

## 原神查询

| 命令 | 说明 |
| --- | --- |
| `#g角色 胡桃` | 角色简要：简介、天赋升级材料合计、满级突破材料、推荐武器和圣遗物，底部附配音。推荐只显示头像和名称，全文用 `#g推荐 胡桃`，天赋全文和伤害倍率用 `#g天赋 胡桃` |
| `g薇纳斯`、`g雷神` | 名字或已收录俗称完全一致时直接出图 |
| `#蝶变` | 武器效果、满级突破材料和推荐角色。推荐角色只显示头像和昵称，没有推荐时显示「暂无角色推荐」 |
| `胡桃立绘` | 全身立绘原图。`原画`、`全身` 相同 |
| `胡桃动作` | 待机和技能动图。`展示`、`待机` 相同 |
| `#图鉴 银釭` | 不限分类搜索，名字中的一部分也能匹配 |

`g名字`、`#名字`、`#角色 名字` 都只在名字完全一致时触发。差一个字不会回复「没有找到」，想模糊搜索用 `#图鉴 关键字`。普通聊天里单独的 `g` 不会被接走。

多个同名词条会给出列表，10 分钟内发送 `g1`、`g2` 打开对应条目。`#图鉴1` 仍然可用。

## 图鉴目录

`#图鉴目录` 先给出全部分类。进入分类后渲染头像和名称，每页 24 条，并带上观测枢的筛选标签。`图鉴列表`、`图鉴分类` 相同。

| 命令 | 说明 |
| --- | --- |
| `#图鉴目录 角色` | 全部角色 |
| `#图鉴目录 角色 火 五星` | 元素和星级 |
| `#图鉴目录 角色 璃月 冰 法器` | 地区、元素、武器 |
| `#图鉴目录 角色 月兆` | 特殊机制 |
| `#图鉴目录 武器 五星 单手剑` | 星级和武器类型 |
| `#图鉴目录 圣遗物 五星` | 圣遗物星级 |
| `#图鉴目录 敌人 BOSS 冰` | 敌人类型和元素 |
| `#图鉴目录 食物 三星 回复类` | 食物星级和类型 |
| `#图鉴目录 材料 蒙德地区特产` | 材料类型 |

条件可以继续叠加。末尾的数字是页码，例如 `#图鉴目录 武器 2`。`5星`、`单手`、`蒙德` 这类简写也能识别。没有结果时，会列出该分类可用的筛选项。

## 日历

| 命令 | 说明 |
| --- | --- |
| `#图鉴日历` | 从今天起 7 天的生日、天赋材料和武器材料 |
| `#图鉴今天` | 只看今天 |
| `#图鉴日历 3` | 自定义天数，最多 14 天 |

材料按系列归组，例如「诗文」下列出绿、蓝、紫各级。周日材料全部开放，图上直接标注，不再逐条罗列。卡池和限时活动不在观测枢这套日历里，所以不显示。

| `z壁纸`、`z壁纸 新春` | 绝区零壁纸收录。绝区零没有表情包分类 |

| `gpv 薇斯纳 2`、`g1` | 翻到下一页，或播放当前列表的第 1 条。一次只发一条 |
| `z爱丽丝` | 立绘、属性、生日身高和角色简介，底部附配音。技能倍率、影画用分项查看 |

推荐角色只保留头像和昵称，多个角色排成头像墙。没有可显示的推荐角色时，卡片写「暂无角色推荐」。

## 说明

- 裸写的「胡桃」不会触发，需要写成 `g胡桃` 或 `#胡桃`。
- `g` 和单独的 `#名字` 只接受完整名字或已收录俗称。差字、少字都不会触发，也不会追问。
- 立绘发送图鉴原图。动作是 GIF 或动图，用合并转发逐条发送，不放进渲染图里。
- `#图鉴视频` 默认关闭，只处理本插件查到的图鉴视频，不会解析群里其他人的视频链接。
- 同名内容可能同时有游戏本体和七圣召唤卡牌。插件优先本体；仍有多个同名结果时才给列表。
- 成就、任务、NPC、洞天这四类条目过万，只在写了分类时查询，避免每次搜索都拉取整表。
- 卡片里的名称、数量和图标都来自图鉴接口。接口没有提供的数值不会自行补算。
- `#图鉴更新` 只出现在主人的帮助里，只做快进拉取，不会覆盖本地改动。拉取完成后需要重启 Yunzai。
- 底图默认读取 `resources/background/bg.png`。可复制 `config/config_default.json` 为 `config/config.json`，修改底图路径、卡片透明度和模糊程度。`config/config.json` 只留在本地，不会提交。

## 目录

```text
genshin-codex/
├─ apps/genshin.js    原神指令与图片渲染
├─ apps/sr.js         星穹铁道指令
├─ apps/zzz.js        绝区零指令
├─ apps/lib/          三款游戏共用的截图、卡片和主题
├─ model/wiki.js      原神搜索、目录筛选和词条解析
├─ model/sr.js        星穹铁道词条解析
├─ model/zzz.js       绝区零词条解析
├─ model/games.js     三款游戏共用的请求、搜索和影音
├─ model/alias.js     读取其他插件的俗称，文件不存在就跳过
├─ config/            底图与样式配置
├─ resources/         默认底图
└─ index.js           Yunzai 插件入口
```
