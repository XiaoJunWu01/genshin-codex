# 观测枢图鉴

适用于 Miao-Yunzai / Yunzai-Bot V3 的原神图鉴插件。数据来自米游社观测枢公开词条，查询结果渲染成图片，覆盖角色、武器、圣遗物、敌人、食物、材料、动物、书籍、成就、任务、秘境、名片等全部分类，并提供生日和突破材料日历。

新内容随观测枢更新。角色目录缓存 6 小时，搜索和词条缓存 30 分钟，到期后自动读取最新词条，不需要为新角色修改插件。

## 安装

在 Yunzai 根目录执行：

```bash
git clone https://gitee.com/wubaojun/genshin-codex.git ./plugins/genshin-codex
```

安装后重启 Yunzai。发送 `#图鉴帮助` 查看分组说明。

## 指令写法

全部指令都支持三种写法，效果相同：

| 写法 | 示例 |
| --- | --- |
| `#` 开头 | `#图鉴帮助`、`#角色 胡桃`、`#图鉴今天` |
| `g` 开头 | `g图鉴帮助`、`g角色 胡桃`、`g图鉴今天` |
| `#g` 开头 | `#g图鉴帮助`、`#g角色 胡桃` |

空格可有可无。`#g天赋 胡桃` 和 `g天赋胡桃` 是同一条指令。下文只列出 `#` 写法。

## 查询

| 命令 | 说明 |
| --- | --- |
| `#g角色 胡桃` | 角色简要：简介、天赋升级材料合计、满级突破材料和推荐武器、圣遗物。天赋全文用 `#g天赋 胡桃` |
| `g薇纳斯`、`g雷神` | 名字或已收录俗称完全一致时直接出图 |
| `#蝶变` | 武器效果、满级突破材料和推荐角色 |
| `胡桃立绘` | 全身立绘原图。`原画`、`全身` 相同 |
| `胡桃动作` | 待机和技能动图。`展示`、`待机` 相同 |
| `#图鉴 银釭` | 不限分类搜索，名字中的一部分也能匹配 |

`g名字`、`#名字`、`#角色 名字` 都只在名字完全一致时触发。差一个字不会回复「没有找到」，想模糊搜索用 `#图鉴 关键字`。普通聊天里单独的 `g` 不会被接走。

多个同名词条会给出列表，10 分钟内发送 `#图鉴1`、`#图鉴2` 打开对应条目。

## 图鉴目录

`#图鉴目录` 先给出全部分类。进入分类后渲染头像和名称，每页 24 条，并带上观测枢的筛选标签。`图鉴列表`、`图鉴分类` 相同。

| 命令 | 说明 |
| --- | --- |
| `#图鉴目录 角色` | 全部角色 |
| `#图鉴目录 角色 火 五星` | 元素和星级 |
| `#图鉴目录 角色 璃月 冰 法器` | 地区、元素、武器 |
| `#图鉴目录 角色 月兆` | 特殊机制 |
| `#图鉴目录 武器 五星 单手剑` | 星级和武器类型 |
| `#图鉴目录 圣遗物 五星` | 圣遗物星级 |
| `#图鉴目录 敌人 BOSS 冰` | 敌人类型和元素 |
| `#图鉴目录 食物 三星 回复类` | 食物星级和类型 |
| `#图鉴目录 材料 蒙德地区特产` | 材料类型 |

条件可以继续叠加。末尾的数字是页码，例如 `#图鉴目录 武器 2`。`5星`、`单手`、`蒙德` 这类简写也能识别。没有结果时，会列出该分类可用的筛选项。

## 日历

| 命令 | 说明 |
| --- | --- |
| `#图鉴日历` | 从今天起 7 天的生日、天赋材料和武器材料 |
| `#图鉴今天` | 只看今天 |
| `#图鉴日历 3` | 自定义天数，最多 14 天 |

材料按系列归组，例如「诗文」下列出绿、蓝、紫各级。周日材料全部开放，图上直接标注，不再逐条罗列。卡池和限时活动不在观测枢这套日历里，所以不显示。

## 说明

- 裸写的「胡桃」不会触发，需要写成 `g胡桃` 或 `#胡桃`。
- `g` 和单独的 `#名字` 只接受完整名字或已收录俗称。差字、少字都不会触发，也不会追问。
- 立绘发送观测枢原图。动作是 GIF 或动图，用合并转发逐条发送，不放进渲染图里，名字和头像使用角色自己的。
- `#图鉴视频` 默认关闭，只处理本插件查到的观测枢视频，不会解析群里其他人的视频链接。
- 观测枢公开词条没有别名字段。`g雷神`、`g绿剑`、`g绝缘` 会读取同目录 miao-plugin 的角色、武器、圣遗物别名。星铁读取 miao-plugin 与 StarRail-plugin，绝区零读取 ZZZ-Plugin 的角色别名。`#图鉴角色 雷神` 里的分类词只用于定位，不会把俗称挡住。

## 星穹铁道和绝区零

星铁用 `s`，绝区零用 `z`，和原神的 `g` 一样。`s流萤`、`#s流萤`、`s 流萤` 是同一条指令，空格可有可无。`#星铁`、`#绝区零` 也能用，不会占用原神的 `#角色`、`g名字`。

| 命令 | 说明 |
| --- | --- |
| `s流萤` | 立绘、资料、满级晋阶材料和推荐光锥、遗器。行迹、星魂、配队用分项查看 |
| `s立绘 流萤` | 角色立绘和画廊原图 |
| `s行迹 流萤`、`s星魂 流萤` | 行迹、星魂全文 |
| `s晋阶 流萤` | 晋阶材料和满级属性。`突破`、`材料` 相同 |
| `s推荐 流萤` | 推荐光锥、遗器和配队 |
| `s影音 流萤` | 先列出封面和简介，发送 `s序号` 播放一条 |
| `s光锥 记一位星神的陨落`、`s遗器 坠星启航地` | 光锥效果和晋阶材料；遗器套装效果 |
| `s表情包`、`s表情包 第1组` | 星铁表情包，按组发送 |
| `z壁纸`、`z壁纸 新春` | 绝区零壁纸收录。绝区零没有表情包分类 |
| `g影音 薇斯纳` | 列出匹配视频的封面和简介，每页 4 条 |
| `g影音 薇斯纳 2`、`#图鉴1` | 翻到下一页，或播放当前列表的第 1 条。一次只发一条 |
| `z爱丽丝` | 立绘、属性、生日身高和角色简介。技能、影画用分项查看 |
| `z音擎 绯月银棺`、`z驱动盘 呼啸沙龙` | 音擎效果和晋升材料、推荐角色；驱动盘套装效果和推荐角色 |
| `z技能 爱丽丝`、`z影画 爱丽丝`、`z突破 爱丽丝` | 技能全文、影画和突破材料 |
| `z影音 爱丽丝` | 先列出封面和简介，发送 `z序号` 播放一条 |

多个结果时发送 `s1`、`z2` 打开。只发 `s` 或 `z` 会列出该游戏的指令。

- 同名内容可能同时有游戏本体和七圣召唤卡牌。插件优先本体；仍有多个同名结果时才给列表。
- 成就、任务、NPC、洞天这四类条目过万，只在写了分类时查询，避免每次搜索都拉取整表。
- 卡片里的名称、数量和图标都来自观测枢接口。接口没有提供的数值不会自行补算。
- `#图鉴更新` 只出现在主人的帮助里，只做快进拉取，不会覆盖本地改动。拉取完成后需要重启 Yunzai。
- 底图默认读取 `resources/background/bg.png`。可复制 `config/config_default.json` 为 `config/config.json`，修改底图路径、卡片透明度和模糊程度。

## 目录

```text
genshin-codex/
├─ apps/wiki.js      指令与图片渲染
├─ model/wiki.js     观测枢搜索、目录筛选和词条解析
├─ config/           底图与样式配置
└─ resources/        默认底图
```
