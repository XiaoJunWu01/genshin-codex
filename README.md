# 观测枢图鉴

适用于 Miao-Yunzai / Yunzai-Bot V3 的原神图鉴插件。数据来自米游社观测枢公开词条，查询后渲染成图片。

## 安装

```bash
git clone https://gitee.com/wubaojun/genshin-codex.git ./plugins/genshin-codex
```

然后重启 Yunzai。

## 指令

`#图鉴帮助` 和 `#g图鉴帮助` 都可以在聊天里看到同样的分组说明。

### 角色

| 命令 | 做什么 |
| --- | --- |
| `#角色 胡桃` | 总览：基础资料、推荐装备、特殊料理 |
| `#g天赋 胡桃` | 天赋全文和每一级升级材料 |
| `#g命座 胡桃` | 六条命之座 |
| `#g突破 胡桃` | 各阶段突破材料和满级合计 |
| `#g故事 胡桃` | 角色介绍、故事和配音 |
| `#g资料 胡桃` | 生日、定位、所属、称号 |
| `#g立绘 胡桃` | 全身立绘 |
| `#g展示 胡桃` | 待机和技能动作 |

`g` 后面可以不加空格，例如 `#g天赋胡桃`。同义写法：`#g技能`、`#g命之座`、`#g星座`、`#g突破材料`、`#g材料`、`#g背景`、`#g简介`、`#g属性`、`#g原画`、`#g动作`。角色支持常用别名，例如 `#角色 雷神`、`#g立绘 万叶`。

### 其他图鉴

| 命令 | 做什么 |
| --- | --- |
| `#武器 狼的末路` | 武器属性和各阶段突破材料 |
| `#圣遗物 绝缘之旗印` | 套装效果、五件单件和推荐角色 |
| `#敌人 丘丘人` | 敌人资料。`#怪物`、`#魔物` 相同 |
| `#食物 甜甜花酿鸡` | 食谱材料和不同品质的食用效果 |
| `#材料 霓裳花` | 材料来源和用途。`#素材`、`#道具` 相同 |

### 搜索

| 命令 | 做什么 |
| --- | --- |
| `#图鉴 银釭` | 不限分类搜索，只有一个结果时直接出图 |
| `#图鉴 武器 狼末` | 限定分类，也支持简称 |
| `#图鉴2` | 打开刚才那次搜索的第 2 条，10 分钟内有效 |
| `#图鉴目录 武器 2` | 按分类翻页浏览 |

角色卡默认只展示总览。天赋、命座、突破材料、故事、立绘和动作展示用 `g` 前缀分开查询，避免和其他插件冲突，也避免一张图过长。总览底部会列出该角色实际有内容的分卡指令。立绘是静态全身图；角色展示是观测枢提供的待机和技能动图，截图时取动图首帧。武器、圣遗物和角色头像会直接显示图标；武器卡会展示突破材料，圣遗物卡会展示五件单件和推荐角色，食物卡会展示带图标的食谱材料。

## 说明

- 裸写的 `#胡桃` 不会触发。必须写分类，例如 `#角色 胡桃`，或使用 `#图鉴 胡桃`。角色的天赋、命座等细分统一加 `g`，例如 `#g天赋 胡桃`。
- 观测枢公开词条没有别名字段。`#角色 雷神`、`#g天赋 万叶` 这类俗称由插件内置表转换成官方名；表里没有的新角色仍要用官方名。
- 观测枢没有单独的“魔物”分类，`#魔物` 查询的是观测枢“敌人”分类。
- 同名内容可能同时有游戏本体和七圣召唤卡牌。插件会优先本体；仍有多个结果时先给列表。
- 卡片图片、名称、数量和图标都来自观测枢接口。接口没有提供的数值不会自行补算。
- 新角色的「角色故事」「神之眼」如果观测枢公开接口还是空的，`#g故事` 只会显示已经公开的介绍和配音。
- 新角色、新武器和新圣遗物不需要改插件。观测枢收录后，用对应名字搜索即可；分类目录会缓存 6 小时，搜索结果缓存 30 分钟。
- 底图默认读取 `resources/background/bg.png`。可复制 `config/config_default.json` 为 `config/config.json` 修改底图、透明度和模糊。

## 目录

```text
genshin-codex/
├─ apps/wiki.js      指令与图片渲染
├─ model/wiki.js     观测枢搜索和词条解析
├─ config/           底图与样式配置
└─ resources/        默认底图
```
