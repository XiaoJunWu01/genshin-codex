# 观测枢图鉴

Yunzai-Bot V3 插件。查询原神、崩坏：星穹铁道、绝区零的公开图鉴，并把结果渲染成图片。

原神数据来自米游社观测枢，星穹铁道和绝区零来自对应游戏的公开图鉴。新内容随图鉴更新：目录缓存 6 小时，搜索和词条缓存 30 分钟，到期后自动读取最新词条，不需要为新角色修改插件。

## 安装

本插件运行在 Yunzai-Bot V3 里，需要先装好机器人本体。Miao-Yunzai、TRSS-Yunzai 以及其他 Yunzai V3 分支都可以。Yunzai 自带插件框架、Puppeteer 截图和 node-fetch，本插件没有额外的 npm 依赖。

在 Yunzai 根目录执行：

```bash
git clone https://gitee.com/wubaojun/genshin-codex.git ./plugins/genshin-codex
```

安装后重启 Yunzai。发送 `#图鉴帮助` 查看帮助。普通用户只看常用指令，主人可看全部指令。

### 必须

| 插件 | 作用 |
| --- | --- |
| Yunzai-Bot V3 | 机器人本体。提供消息插件、Puppeteer 截图和网络请求。没有它，本插件无法加载，也不能出图 |

不需要单独安装 puppeteer、node-fetch 或其他图鉴插件。

### 可选

俗称不是图鉴接口提供的。不装下面的插件，正式名字仍然可以查询，例如 `g胡桃`、`*流萤`、`%妮可`；`g雷神`、`s希儿专武` 这类俗称需要对应插件的别名文件。缺哪个就跳过哪一份，不影响其余功能。

| 插件 | 作用 |
| --- | --- |
| [miao-plugin](https://github.com/yoimiya-kokomi/miao-plugin) | 原神角色、武器、圣遗物俗称；星穹铁道角色、光锥、遗器俗称 |
| [StarRail-plugin](https://gitee.com/hewang1an/StarRail-plugin) | 星穹铁道角色俗称 |
| [ZZZ-Plugin](https://gitee.com/ZZZ-Plugin/ZZZ-Plugin) | 绝区零角色俗称 |
| [Guoba-Plugin](https://gitee.com/guoba-yunzai/guoba-plugin) | 在网页里修改帮助主题、颜色、背景图和帮助内容 |

原神角色俗称也可以读取 Yunzai 自带的 `genshin` 插件别名。

## 指令前缀

三个游戏的前缀互不混用：

| 游戏 | 主前缀 | 字母前缀 | 示例 |
| --- | --- | --- | --- |
| 原神 | `#` | `g` | `#胡桃`、`g胡桃`、`g胡桃专武` |
| 星穹铁道 | `*` | `s` | `*流萤`、`s流萤`、`s流萤专武` |
| 绝区零 | `%` | `z` | `%妮可`、`z妮可`、`z妮可专武` |

空格可有可无。`g天赋 胡桃` 和 `g天赋胡桃` 是同一条指令。`#` 只查原神，不会再进入星铁或绝区零。

尚未实装但已收录的角色，例如 `g米提亚`、`#米提亚`，会回复「暂无该角色数据，敬请期待」。没有收录的错字或不存在的名字不会回复。

## 锅巴

安装 Guoba-Plugin 后，在网页里打开「观测枢图鉴」：

- 选择帮助主题、列数、字体、毛玻璃、透明度和模糊程度。
- 用颜色选择器修改标题、指令和说明文字颜色。
- 上传帮助背景图。
- 在「帮助分组」里新增、删除和修改分组、指令、说明，并设置哪些分组对普通用户可见。

修改后重新发送 `#图鉴帮助` 即使用新样式和内容。

## 说明

- 裸写的「胡桃」不会触发，需要使用对应游戏的前缀。
- 多个同名结果才会给出序号列表，10 分钟内发送 `g1`、`s1`、`z1` 打开。
- 属性关键词按完整词分别上色，例如风、火、水、雷、冰、岩、草、物理、以太、电，不会把整句都变成同一种颜色。
- `#图鉴更新` 只对主人显示，只做快进拉取，不会覆盖本地改动。拉取完成后需要重启 Yunzai。
- 本地样式保存在 `config/config.json`，该文件不会提交。

## 目录

```text
genshin-codex/
├─ apps/genshin.js       原神指令、帮助和图片渲染
├─ apps/sr.js            星穹铁道指令
├─ apps/zzz.js           绝区零指令
├─ apps/lib/             三款游戏共用的截图、卡片和主题
├─ model/wiki.js         原神搜索、目录筛选和词条解析
├─ model/sr.js           星穹铁道词条解析
├─ model/zzz.js          绝区零词条解析
├─ model/games.js        三款游戏共用的请求、搜索和影音
├─ model/alias.js        读取其他插件和本插件自带的俗称
├─ config/help.js        默认可编辑帮助内容
├─ config/config.js      帮助样式配置
├─ guoba.support.js      锅巴配置面板
├─ resources/            默认背景和自带俗称
└─ index.js              Yunzai 插件入口
```
