# 观测枢图鉴

适用于 Miao-Yunzai / Yunzai-Bot V3 的原神图鉴插件。对接米游社观测枢公开词条，把角色、武器、圣遗物、敌人、食物和材料渲染成图片。

新内容随观测枢更新。角色目录缓存 6 小时，搜索和词条缓存 30 分钟，到期后自动读取最新词条，不需要为新角色改插件。

## 安装

```bash
git clone https://gitee.com/wubaojun/genshin-codex.git ./plugins/genshin-codex
```

安装后重启 Yunzai。发送 `#图鉴帮助` 查看分组说明。

## 角色

| 命令 | 说明 |
| --- | --- |
| `#角色 胡桃`、`g薇纳斯` | 角色总览 |
| `#g天赋 胡桃` | 天赋全文和升级材料 |
| `#g命座 胡桃` | 六条命之座 |
| `#g突破 胡桃` | 突破材料和满级合计 |
| `#g故事 胡桃` | 角色介绍、故事和配音 |
| `#g资料 胡桃` | 生日、称号、所属和定位 |
| `胡桃立绘` | 全身立绘原图 |
| `胡桃动作` | 待机和技能动图 |

`g` 后面可以不加空格。`#g技能`、`#g命之座`、`#g原画`、`#g展示` 仍然可用。

## 图鉴目录

`#图鉴目录` 先给出分类。进入分类后渲染头像和名称，每页 24 条，并带上观测枢的筛选标签。

| 命令 | 说明 |
| --- | --- |
| `#图鉴目录 角色` | 全部角色 |
| `#图鉴目录 角色 火 五星` | 元素和星级 |
| `#图鉴目录 角色 璃月 冰 法器` | 地区、元素、武器 |
| `#图鉴目录 角色 月兆` | 特殊机制 |
| `#图鉴目录 武器 五星 单手剑` | 星级和武器类型 |
| `#图鉴目录 圣遗物 五星` | 圣遗物星级 |
| `#图鉴目录 敌人 BOSS 冰` | 敌人类型和元素 |
| `#图鉴目录 食物 三星 回复类` | 食物星级和类型 |
| `#图鉴目录 材料 蒙德地区特产` | 材料类型 |

条件可以继续叠加。末尾的数字是页码，例如 `#图鉴目录 武器 2`。`5星`、`单手`、`蒙德` 这类简写也能识别。没有结果时，会列出该分类可用的筛选项。

## 搜索和设置

| 命令 | 说明 |
| --- | --- |
| `#图鉴 银釭` | 不限分类搜索，唯一结果直接出图 |
| `#图鉴2` | 打开上一次搜索的第 2 条，10 分钟内有效 |
| `#图鉴视频开` | 查询角色视频词条时直接发送视频 |
| `#图鉴视频关` | 关闭视频，默认关闭 |
| `#图鉴更新` | 主人更新插件，只做快进拉取 |

## 说明

- 裸写的 `#胡桃` 不会触发。角色可以直接写 `g薇纳斯`，分类也可以写在后面，例如 `饰金圣遗物`、`丘丘人敌人`。
- 立绘发送观测枢原图。动作是 GIF，用合并转发逐条发送，名字和头像使用角色自己的。
- `#图鉴视频` 默认关闭，只处理本插件查到的观测枢视频，不会解析群里其他人的视频链接。
- 观测枢公开词条没有别名字段。`g雷神`、`#g天赋 万叶` 这类俗称由插件内置表转换成官方名。
- 同名内容可能同时有游戏本体和七圣召唤卡牌。插件优先本体；仍有多个同名结果时才给列表。
- 卡片里的名称、数量和图标都来自观测枢接口。接口没有提供的数值不会自行补算。
- `#图鉴更新` 只做快进拉取，不会覆盖本地改动。拉取完成后需要重启 Yunzai。
- 底图默认读取 `resources/background/bg.png`。可复制 `config/config_default.json` 为 `config/config.json`，修改底图、透明度和模糊。

## 目录

```text
genshin-codex/
├─ apps/wiki.js      指令与图片渲染
├─ model/wiki.js     观测枢搜索、目录筛选和词条解析
├─ config/           底图与样式配置
└─ resources/        默认底图
```
