# 观测枢图鉴

适用于 Miao-Yunzai / Yunzai-Bot V3 的原神图鉴插件。数据来自米游社观测枢公开词条，查询后渲染成图片。

## 安装

```bash
git clone https://gitee.com/wubaojun/genshin-codex.git ./plugins/genshin-codex
```

然后重启 Yunzai。

## 指令

`#图鉴帮助` 和 `#g图鉴帮助` 会发一张分组说明。

### 角色

| 命令 | 做什么 |
| --- | --- |
| `#角色 胡桃`、`g薇纳斯` | 名字能对上时直接出总览 |
| `#g天赋 胡桃` | 天赋全文和每一级升级材料 |
| `#g命座 胡桃` | 六条命之座 |
| `#g突破 胡桃` | 各阶段突破材料和满级合计 |
| `#g故事 胡桃` | 角色介绍、故事和配音 |
| `#g资料 胡桃` | 生日、定位、所属、称号 |
| `胡桃立绘` | 全身立绘原图，不经过卡片裁切 |
| `胡桃动作` | 待机和技能动图，合并转发并带动作名 |

`g` 后面可以不加空格。`#g技能`、`#g命之座`、`#g原画`、`#g展示` 这些同义写法仍然可用。只有重名时才给出列表，再用 `#图鉴2` 打开其中一条。

### 其他图鉴

| 命令 | 做什么 |
| --- | --- |
| `#武器 狼的末路`、`狼末武器` | 武器属性和突破材料 |
| `#圣遗物 饰金`、`饰金圣遗物` | 套装效果、单件和推荐角色 |
| `#敌人 丘丘人`、`丘丘人敌人` | 敌人资料。`#怪物`、`#魔物` 相同 |
| `#食物 甜甜花酿鸡` | 食谱材料和食用效果 |
| `#材料 霓裳花` | 材料来源和用途 |

### 搜索和视频

| 命令 | 做什么 |
| --- | --- |
| `#图鉴 银釭` | 不限分类搜索，唯一结果直接出图 |
| `#图鉴2` | 打开刚才那次搜索的第 2 条，10 分钟内有效 |
| `#图鉴目录 武器 2` | 按分类翻页浏览 |
| `#图鉴视频开` | 开启后，查询本插件的角色视频词条会直接发视频 |
| `#图鉴视频关` | 关闭视频，默认就是关 |

## 说明

- 裸写的 `#胡桃` 不会触发。角色可以直接写 `g薇纳斯`，分类可以写在后面，例如 `饰金圣遗物`、`丘丘人敌人`。
- 立绘发送观测枢原图。动作是 GIF，用合并转发逐条发送，并写上待机、攻击、战技、爆发这些名字。
- `#图鉴视频` 默认关闭，而且只处理本插件查到的观测枢视频。群里其他人的 B 站链接不会被解析。
- 观测枢公开词条没有别名字段。`g雷神`、`#g天赋 万叶` 这类俗称由插件内置表转换成官方名。
- 同名内容可能同时有游戏本体和七圣召唤卡牌。插件会优先本体；仍有多个同名结果时才给列表。
- 卡片里的名称、数量和图标都来自观测枢接口。接口没有提供的数值不会自行补算。
- 新角色、新武器和新圣遗物不需要改插件。分类目录缓存 6 小时，搜索结果缓存 30 分钟。
- 底图默认读取 `resources/background/bg.png`。可复制 `config/config_default.json` 为 `config/config.json` 修改底图、透明度和模糊。

## 目录

```text
genshin-codex/
├─ apps/wiki.js      指令与图片渲染
├─ model/wiki.js     观测枢搜索和词条解析
├─ config/           底图与样式配置
└─ resources/        默认底图
```
